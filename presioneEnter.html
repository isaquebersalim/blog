Função em C para fechar o terminal somente após pressionar a tecla enter

📅 Data: 15/04/2025
🏷️ Categoria: Tutorial

🧠 Contexto

Depois de salvar determinado código da linguagem C, é necessário fazer o Debbuging.
No VsCode, assim que o código se encerrava o terminal também fechava automaticamente, então essa função trava o terminal, até que ocorra a ação de pressionar a tecla enter.

🔧 O Que Fiz

Código para não fechar o terminal até que pressione a tecla enter.

        
            Pressione Enter para sair

            printf("\nPressione Enter para sair...");
            while (getchar() != '\n'); // limpa buffer
            getchar();
